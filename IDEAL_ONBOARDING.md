# MetricStream Connector — идеальный первый запуск

Источник: `ONBOARDING_FIRST_LAUNCH_STANDARD.md`. Целевой пользователь: Risk/
Compliance-менеджер, использующий MetricStream для Risk Management, Issues,
Controls testing и Assessments.

## 1. Credential type
Статический API Key (MetricStream Admin settings), плюс обязательный
base_url (у каждого клиента свой домен — как у OneTrust/AuditBoard).

## 2. Идеальный флоу
1. **Первое открытие** — `Empty` с объяснением: "создайте API-ключ в
   MetricStream Admin и укажите домен вашего тенанта".
2. **Форма подключения** — Label + Instance URL (обязательное) + API Key.
3. **После успеха** — сразу открывается сводка `audit_risk_posture`: сколько
   Issues открыто по severity, сколько высокорисковых Risks, сколько
   Controls не проходят тестирование, процент завершения Assessments.
4. **Работа с Issues** — список Issues, открытие одного — создание/
   обновление статуса прямо из чата.
5. **Множественные тенанты** — поддерживаются несколько сохранённых
   подключений с явным label, как в остальных GRC-приложениях.

## 3. Открытый технический долг
Discovery-документ для этого приложения написан без подтверждённого чтения
живой документации MetricStream (веб-поиск был недоступен в этой сессии) —
как только он снова заработает, нужно свериться и поправить эндпоинты при
необходимости.
